Prop Guard live on Solana mainnet · Solami

A prop-firm risk guard for Jupiter Perps traders: daily loss limit on the UTC day, liquidation alarms, exposure, Telegram alerts and a stream-health panel — fed by Solami Yellowstone gRPC with RPC fallback and from_slot replay.

  1. Live data. The real guard on mainnet: positions, custodies and Doves oracles decoded from the Solami gRPC stream; slot lag vs the RPC head, oracle age, data vs pings.
  2. Trader value. Liquidation price from Jupiter's own formula in exact integer math — matched against Jupiter's API on camera; daily loss vs limit with the anchor source stated.
  3. Resilience, for real. A chaos proxy pauses the stream: after 15 s of silence the guard switches to RPC polling by itself and hands back when bytes flow again. Then the connection is dropped: reconnect with from_slot replay.
  4. Alerts. Telegram alerts with dedup and cooldown — the ones in the video were really sent.
